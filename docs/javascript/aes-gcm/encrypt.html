オフライン暗号化/復号（共通鍵）— AES-256-GCM + PBKDF2

外部ライブラリなし。暗号文フォーマットは ENCv1.<salt>.<iv>.<cipher>（Base64URL）。
鍵長: 6〜30文字 Salt: 16 bytes IV: 12 bytes PBKDF2(SHA-256) AES-GCM(256)
準備完了。
注意: このツールは「ブラウザ内だけで暗号化/復号」しますが、端末がマルウェアや拡張機能で侵害されている場合は保護できません。 また、crypto.subtle は「Secure Context」でのみ使えます。動かない場合は localhost で開く（オフラインでも可）などを検討してください。[1](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto)[2](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/subtle)[3](https://qiita.com/ripple_naip/items/e21db85fbd43f3aebf76)
